Build a complete, production-quality frontend prototype for a modern peer-to-peer e-commerce marketplace called:

SHOPSPHERE

Tagline:
"Buy. Sell. Discover."

============================================================
1. PROJECT OVERVIEW
============================================================

ShopSphere is a cloud-ready e-commerce marketplace where users can both BUY and SELL products using the same account.

The basic concept is:

USER
  |
  ├── Browse products
  ├── Search products
  ├── Filter products
  ├── View product details
  ├── Add products to cart
  ├── Checkout
  ├── Place orders
  ├── View order history
  |
  └── Sell products
       ├── Create listing
       ├── Edit listing
       ├── Delete listing
       ├── Manage stock
       └── View received orders

There will also be an ADMIN role with a separate Admin Dashboard for managing the marketplace.

This is a student cloud computing / e-commerce project.

The frontend should be designed so that it can later be connected to AWS services:

React Frontend
      ↓
Amazon API Gateway
      ↓
AWS Lambda
      ↓
Amazon DynamoDB

Product images:
React
      ↓
Amazon S3

Authentication:
React
      ↓
Amazon Cognito

Analytics:
User Events
      ↓
Amazon S3
      ↓
AWS Glue
      ↓
Amazon Athena
      ↓
Analytics / Recommendation Engine

IMPORTANT:

For this phase, DO NOT implement the actual AWS backend.

Build a fully functional frontend using mock/local data.

However, structure the application so that replacing the mock services with AWS API calls later is easy.
